# La web es una pieza del sistema de composición

El Manual de Marca v2.1 define plantillas para story, feed, carrusel, ficha, menú, packaging y WhatsApp — pero no define la web. Se decidió que la landing de sorbolabs.com se comporta como **una sola pieza**: un viewport, orden vertical fijo (header → titular → bajada → acción → bloque de datos → Doe), una sola idea (estamos armando algo) y una sola acción (anotarse en la lista de espera). No hay navegación, ni scroll de secciones, ni footer tradicional.

La alternativa era un sitio multi-sección (historia, menú, contacto). Se rechazó porque el local está por abrir sin fecha, no hay menú ni horarios que publicar, y el sistema premia el aire: una página larga habría sido relleno. Cuando exista contenido real para más superficies, cada una será su propia pieza o se definirá el formato web en el manual.
